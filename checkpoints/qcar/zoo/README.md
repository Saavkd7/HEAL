# QCar HEAL model zoo

Nine HEAL fusion methods trained on the same real-world data from two Quanser
QCar vehicles, with the same training recipe. The data comes from a physical
testbed at Concordia University: one front camera per car, Vicon ground truth,
real calibration, and walls that block each car's view.

Code, configs and usage: the `qcar-testbed-integration` branch of
[github.com/Saavkd7/HEAL](https://github.com/Saavkd7/HEAL/tree/qcar-testbed-integration)
(start at `qcar/README.md`). The weights run on top of
[HEAL](https://github.com/yifanlu0227/HEAL) (ICLR 2024).

## Download

From the HEAL repo root, so the files land where the code expects them:

```bash
hf download Saavkd7/qcar-heal-zoo --local-dir checkpoints/qcar/zoo
```

Each `<method>/` folder then has the weights (`net_epoch_bestval_at*.pth`),
the exact config (`config.yaml`, `resolved_hypes.json`) and the validation
metrics (`eval_validate.json`). Evaluate one with:

```bash
python qcar/eval.py --model_dir checkpoints/qcar/zoo/<method>
```

or replay it round by round in `qcar_rounds.ipynb`.

## Results

Validation split: 237 frames from 2 held-out trajectories (`qcar_coop_07`,
`qcar_coop_08`). Camera-only, 2 agents. "Ego-only" runs the same model
without the peer's features.

| method | AP@0.2 coop | AP@0.5 coop | AP@0.5 ego-only |
|---|---|---|---|
| pyramid | 0.919 | **0.891** | 0.406 |
| coalign | 0.918 | 0.881 | 0.417 |
| who2com | **0.929** | 0.871 | 0.534 |
| v2xvit | 0.920 | 0.855 | 0.489 |
| where2comm | 0.887 | 0.723 | 0.160 |
| disconet | 0.860 | 0.711 | 0.225 |
| cobevt | 0.883 | 0.517 | 0.268 |
| max | 0.875 | 0.487 | 0.038 |
| att | 0.825 | 0.451 | 0.369 |

Confidence intervals (paired block bootstrap), per-trajectory AP and the
fusion gain are in `COMPARISON.md`.

**Caveats.**
- These are development numbers. The validation split also chose each run's
  best epoch, and there is no independent test trajectory yet.
- `att`, `max` and `disconet` often rotate boxes that come from the peer by
  about 90° (they fuse pixel by pixel). That is why they drop at IoU 0.5.
- V2VNet is not included: its training run collapsed. A retrain is pending.

## Training

- **Recipe:** all methods share it (see `qcar/zoo.json`). The configs are
  generated by `qcar/zoo.py`.
- **Initialization:**
  - `att`, `max`, `disconet` and `v2xvit` start from their released OPV2V
    camera checkpoints.
  - `cobevt`, `where2comm`, `who2com`, `coalign` and `pyramid` reuse the
    encoder of the camera AttFuse checkpoint; their fusion and heads start
    from scratch.
- **Scale:** model space is 10x the real world in x/y (1 unit = 10 cm),
  because the QCars are about 1/10 the size of a car.

## Data

The QCar recordings and the built dataset (`CoopFront`) are not public yet.
The code that builds the dataset from the raw ROS bags is in the GitHub repo
(`qcar_testbed_integration/`).
